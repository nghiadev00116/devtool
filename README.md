# 🛠️ DevTool & Knowledge Base

Kho lưu trữ cá nhân này được thiết lập với mục đích **học tập, làm việc**, cũng như thu thập và lưu giữ các **mẹo (tips), tiện ích (utilities), và script** hữu ích trong quá trình phát triển phần mềm.

## 📂 Danh sách các file & thư mục

Dưới đây là tổng quan và chức năng của từng file hiện có trong repo này để bạn dễ dàng tra cứu:

| Tên File | Mô tả hoạt động / Chức năng chính |
| :--- | :--- |
| 📄 **`README.md`** | File bạn đang đọc, đóng vai trò như một bản đồ chỉ dẫn. Mô tả tổng quan về dự án và giải thích chức năng của toàn bộ các file/thư mục khác trong repo. |
| 🤖 **`android16-pixel9a.md`** | Hướng dẫn chi tiết root Google Pixel 9a (Android 16) bằng cách patch `init_boot.img` với Magisk, và cấp quyền Device Owner cho ứng dụng qua ADB. |
| 🖥️ **`anydesk-ubuntu-setup.md`** | Các lệnh cài đặt & cấu hình AnyDesk trên Ubuntu, kèm bước tắt Wayland để nhận chuột/bàn phím. |
| 🧹 **`cleanup-commands.md`** | Bí kíp dọn dẹp ổ cứng (MacBook/SSD). Các lệnh Terminal an toàn giúp giải phóng bộ nhớ từ AI (Hugging Face), Docker, Node.js, Python/Conda và macOS. |
| 💽 **`create-usb-by-macos.md`** | Hướng dẫn tạo USB cài Windows 10/11 chuẩn UEFI trên macOS, xử lý file `install.wim` lớn hơn 4GB bằng `wimlib`. |
| 🍏 **`hackintosh-tips.md`** | Ghi chú, mẹo và cách sửa các lỗi OpenCore thường gặp khi cài Hackintosh (lỗi Vault, System-ID, boot args, link EFI). |
| 🔐 **`password.py`** | Tool bảo mật 6 lớp (chạy bằng Python/Terminal). Mã hóa & giải mã mật khẩu theo công thức 6 số key — nhập key lúc chạy, không lưu cứng trong file. |
| 🔐 **`password-tool.html`** | Phiên bản web của tool bảo mật 6 lớp. Mở bằng trình duyệt bất kỳ (chạy được **offline**), giao diện giải mã/mã hóa, không gửi dữ liệu đi đâu. |
| 🖨️ **`printer-K144HS0-ubuntu.sh`** | Script tự động cài máy in bill nhiệt Zjiang 80mm (đã vá lỗi cho Ubuntu phiên bản mới), tự dò cổng USB và đặt máy in mặc định. |
| 🖨️ **`printer-star-bsc10-ubuntu.sh`** | Script cài máy in Star BSC10 trên Ubuntu — tự build filter bằng gcc và khai báo với CUPS. |
| 🪟 **`script-setup-dotnet-window.md`** | Script PowerShell tự động dựng toàn bộ môi trường .NET Developer trên Windows mới (SDK, IDE, DB tools, tiện ích). |
| 📋 **`setup-dotnet-window.md`** | Checklist thủ công các phần mềm & cấu hình cần thiết khi setup máy Windows cho vị trí .NET Developer. |
| ⚙️ **`n8n-instructions.md`** | Các lệnh và thông tin cấu hình cho n8n self-host (khởi động, reset user, thông tin đăng nhập local). |
