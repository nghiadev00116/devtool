# 🛠️ DevTool & Knowledge Base

## 📂 Danh sách các file & thư mục

Dưới đây là tổng quan và chức năng của từng file hiện có trong repo này để bạn dễ dàng tra cứu:

| Tên File | Mô tả hoạt động / Chức năng chính |
| :--- | :--- |
| 📄 **`cleanup-commands.md`** | Bí kíp dọn dẹp ổ cứng (MacBook/SSD). Chứa các lệnh Terminal an toàn và tối ưu giúp giải phóng hàng chục GB bộ nhớ từ các môi trường như AI (Hugging Face), Docker, Node.js, Python/Conda và macOS System. |

---
> 💡 **Ghi chú:** Repo này sẽ tiếp tục được mở rộng. Mỗi khi có dự án, tiện ích hay bí kíp mới được thêm vào, bạn nhớ cập nhật lại thông tin vào file `README.md` này để tiện cho việc tra cứu sau này nhé!
